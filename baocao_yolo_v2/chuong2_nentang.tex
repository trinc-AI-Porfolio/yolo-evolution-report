\section{Pipeline Object Detection hiện đại}

Một detector hiện đại gồm 3 phần:
\begin{itemize}
    \item \textbf{Backbone:} Mạng trích xuất features từ ảnh (VGG, ResNet, Darknet, CSPDarknet, EfficientNet...)
    \item \textbf{Neck:} Kết hợp features ở nhiều scales (FPN, PAN, BiFPN)
    \item \textbf{Head:} Dự đoán bounding boxes và classes
\end{itemize}

\section{Các khái niệm cốt lõi}

\subsection{IoU (Intersection over Union)}
Đo mức trùng lặp giữa predicted box và ground truth:
\[
\text{IoU} = \frac{|B_p \cap B_{gt}|}{|B_p \cup B_{gt}|}
\]

\subsection{mAP (mean Average Precision)}
\begin{itemize}
    \item \textbf{mAP@50:} Tính AP ở ngưỡng IoU = 0.5
    \item \textbf{mAP@50:95:} Trung bình AP ở IoU từ 0.5 đến 0.95 (bước 0.05) — metric chính trên COCO
\end{itemize}

\subsection{Anchor Boxes}
Các hộp mẫu (templates) được định nghĩa trước với kích thước và tỷ lệ khác nhau. Model dự đoán \textbf{offsets} so với anchors thay vì tọa độ tuyệt đối.

\subsection{NMS (Non-Maximum Suppression)}
Thuật toán loại bỏ bounding boxes trùng lặp: giữ box có confidence cao nhất, loại bỏ các boxes có IoU > ngưỡng với box đã chọn.

\section{Datasets chuẩn}

\begin{itemize}
    \item \textbf{PASCAL VOC} (2007/2012): 20 classes, ~10K ảnh. Metric: mAP@50.
    \item \textbf{MS COCO:} 80 classes, 330K ảnh. Metric: mAP@50:95. Benchmark chính từ v3.
    \item \textbf{LVIS:} 1203 categories. Dùng cho open-vocabulary (YOLOE).
\end{itemize}
