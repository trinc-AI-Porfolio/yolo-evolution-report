\chapter{KẾT LUẬN VÀ KHUYẾN NGHỊ}

\section{Tổng kết}

Qua 11 năm phát triển (2015--2026), YOLO đã trải qua hành trình đáng chú ý:

\begin{itemize}
    \item \textbf{Accuracy:} Từ 63.4\% (VOC, v1) lên $\sim$57.2\% (COCO, YOLO26) — cải thiện liên tục trên benchmark khó hơn nhiều
    \item \textbf{Kiến trúc:} Từ CNN 24 lớp thô sơ → Attention-centric với Area Attention
    \item \textbf{Detection paradigm:} Grid → Anchor → Anchor-free → NMS-free
    \item \textbf{Phạm vi:} Từ detection only → 6 tác vụ + open-vocabulary
    \item \textbf{Ecosystem:} Từ compile C code → \texttt{pip install}, 1 dòng code train
    \item \textbf{3 nhánh phát triển:} Redmon (v1--v3), Wang (v4,v7,v9), Ultralytics (v5,v8,v11,v26)
\end{itemize}

\textbf{Bài học quan trọng:} Đời sau \textbf{không phải lúc nào cũng tốt hơn} đời trước ở mọi tiêu chí. v8 thua v7 accuracy, v10 thua v9 mAP. Mỗi version tối ưu cho mục đích khác nhau.

\section{Hướng phát triển tương lai}

\begin{enumerate}
    \item \textbf{YOLO + LLM:} Kết hợp vision và language models cho scene understanding
    \item \textbf{Edge AI:} Tối ưu cho camera nhúng, drone, IoT
    \item \textbf{Video understanding:} Từ frame-by-frame → temporal reasoning
    \item \textbf{3D detection:} Mở rộng từ 2D bounding box sang 3D
    \item \textbf{Self-supervised:} Giảm phụ thuộc labeled data
\end{enumerate}

\section*{Lời cuối}

\begin{quote}
\textit{``Sự thật cuối cùng: Chênh lệch 1--3\% mAP giữa các version trên COCO có thể không có ý nghĩa trên dataset thực tế. Data chất lượng quan trọng hơn chọn model.''}
\end{quote}
